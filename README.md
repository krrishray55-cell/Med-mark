# Medimark Pharmacy & Clinic

Static site for GitHub Pages (https://krrishray55-cell.github.io/Med-mark/).

All files sit in the repository root, with no sub-folders and no build step:

    index.html   style.css   logo.png   storefront.jpg   favicon.png

All paths are relative (`style.css`, `logo.png`), so they work under `/Med-mark/`.
Pages setting: Deploy from branch `main`, folder `/ (root)`.
